# SketchpadNext

SketchpadNext 是一个浏览器原生的现代动态几何工作台，使用 SVG 和 ES 模块实现，不依赖第三方软件包。当前版本已经覆盖常用动态构造、标识、度量、变换、轨迹、函数绘图、动作按钮、多页面和自定义工具。

在线版：[https://ylopah.github.io/SketchpadNext/](https://ylopah.github.io/SketchpadNext/)

## 启动

直接双击 **`SketchpadNext.html`** 即可使用。这是已生成的单文件版，不需要 CMD、Node.js 或本地服务，断网也可运行。建议使用最新版 Chrome 或 Edge。

开发源码时仍可以在本目录运行：

```powershell
npm start
```

然后打开 `http://127.0.0.1:4173/`。

源码修改后运行 `npm run build:standalone`，即可重新生成可直接双击的 `SketchpadNext.html`。

## 常用操作

- 选择工具中连续点击可累加选择，再点已选对象可取消；空白拖动可框选；拖动尚未选中的对象时会自动只选中并移动它。
- 在交叉附近单击可直接建立精确动态交点。
- 中键、右键或按住空格后左键拖动画布，滚轮缩放；触屏可双指平移和捏合缩放。
- 手机会自动使用紧凑界面：竖屏为底部可滑动工具栏，横屏为左侧窄工具栏；“属性”打开抽屉，“更多”收纳文件和设置操作。顶部徽标显示设备与浏览器，点击或悬停可查看完整 UA。
- 自由点和路径点直接拖动；中点、交点、外心等派生点拖动时会整体平移其可移动构造。
- `Esc` 优先取消当前构造步骤，再清空选择，最后返回选择工具。
- 点标签可在点附近拖动；属性检查器可改点名、大小、线宽、颜色和虚实线。点名或文本中的 `A_1`、`x^2` 会显示上下标，也支持 `\alpha`、`\angle`、`\perp` 等常用数学符号。
- 选择状态下双击独立文本可重新编辑；点名输入在回车或失焦时统一提交，清空不会删除点。
- `Ctrl+C`、`Ctrl+V`、`Ctrl+D`：复制、粘贴、原位复制。
- `Ctrl+S`：保存到当前 `.spn` 工程；`Ctrl+Shift+S`：另存为新工程。
- 点击顶部“复制 LaTeX”，可把当前页面、当前视图的完整 TikZ/LaTeX 代码直接复制到剪贴板。
- `Ctrl+Z`、`Ctrl+Y`：撤销和重做。
- `Ctrl+H`：隐藏；`Ctrl+Shift+H`：显示全部隐藏对象。
- 数据、变换、度量、显示和构造命令位于画布上方菜单。
- 先选中任意多个点和任意多条线形对象，再点“平行线”或“垂线”，会按“所有点 × 所有线”一次构造完整组合。
- 先选中两条具有公共端点的边即可作角平分线；角平分线和中垂线工具也允许直接在画布上点出新点。
- 选中三个不共线的点后，可从“构造”菜单创建动态重心、内心、垂心和内切圆。
- “移到最前/最后”支持图片、图形、点和文字之间的跨类型层级调整。
- 开启“吸附与网格”会同步显示网格；吸附只约束几何落点和点拖动，不会让文本、图片或标签移动卡顿。
- 工具快捷键统一为 `Alt+字母`，可在顶部“设置”中关闭。顶部“说明”包含所有工具、数学输入和画布操作的完整用法。
- “设置”会保存默认点线样式、吸附、快捷键、度量小数位、文本字号和点名字号，下一次打开仍然生效；新建点默认使用黑色。

完整功能见 [FEATURES.md](./FEATURES.md)，手册对照见 [GSP_MANUAL_PARITY.md](./GSP_MANUAL_PARITY.md)，大胆的后续设想见 [ROADMAP_IDEAS.md](./ROADMAP_IDEAS.md)。

## 本压缩包范围

本包仅用于 SketchpadNext 动态几何画板本体的开发与交接。自然语言作图、自动出题、候选发现及证明实验均未包含。

## 文件格式

- 新建工程首次“保存”会让你选择 `.spn` 文件位置，之后“保存”或 `Ctrl+S` 会直接写回当前工程；刷新页面后仍会记住该文件（浏览器可能再次询问修改权限）。“另存为”可建立新副本。
- `.spn` 内部使用开放的 JSON 数据结构；旧版 SketchpadNext `.json` 工程仍可直接打开。
- 图片输出功能按产品决策移除；需要图片时使用系统截图工具。
- LaTeX 导出是当前画面的静态 TikZ 快照；含中文文本时建议使用 XeLaTeX 或 LuaLaTeX 编译。
- 几何画板专有的 `.gsp` 二进制文件暂不在兼容范围内。
